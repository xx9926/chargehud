# 充电悬浮窗 ChargeHud

[中文](README.md) | **English**（[README.en.md](README.en.md)）

一个只关心充电的 Android 小工具：把**实时充电功率（W）**、**电池温度（℃）**（也可以再加上电压和电流）
钉在屏幕最上层，方便插着充电器时直接看到当前充得多快、机身有多热。

> 下载：**[Releases](https://github.com/xx9926/chargehud/releases/latest)** 里有可直接安装的 apk。

- 悬浮窗默认两行（功率 / 温度），在「外观」里可以勾选要显示哪几项：功率 / 温度 / 电压 / 电流，
  **勾选的先后顺序就是各行从上到下的排列顺序**（取消再勾回来会排到最后），
  四行都显示时窗口自动变高，一行都不勾则整个窗口收起
- 颜色 / 字号 / 底色 / 位置都可调，设置页分「外观」「位置」「档案」「更多」四段，点标题展开收起；
  「更多」里再分「主题」「提醒」和「高级」三个子项，前者是相册照片 / 短视频当背景，中者收四条充电提醒，
  后者收取数与后台行为相关的开关
- 「更多 → 主题」可以挑一张相册照片或一段短视频当 App 背景，配背景色、0~100 透明度和高斯模糊，
  拖动滑块实时预览；背景一直铺到状态栏底下（沉浸式），状态栏图标深浅跟着背景亮度自动换
- 拖动随意摆放，单击回到设置页；「位置」里有锁定开关，锁上后拖不动
- 下拉状态栏磁贴「充电悬浮」，点一下开 / 关悬浮窗，磁贴颜色当场跟着变（Quick Settings Tile）
- 常驻通知显示当前功率与温度，带「关闭悬浮窗」和「锁定 / 解锁」两个按钮；
  不想让通知占位可以在「更多 → 高级」里关掉常驻，代价是后台更容易被系统回收
- 开机自动恢复上次的开关状态与位置
- 「更多 → 高级」里的**隐藏后台**开关：打开后设置页不进最近任务，清后台时没有可滑掉的目标，不会顺手把悬浮窗服务一起杀掉；
  再进设置点悬浮窗或桌面图标即可（切换从下次进入设置页开始生效）
- 「档案」把每次充电记下来：时长、起止电量、峰值 / 均值功率、充进多少 mAh、温度峰值，
  并画出**功率与电量随时间**的折线图；记录只存在手机本地
- 四条充电提醒（高温 / 慢充 / 涓流 / 充满，走独立通知渠道）：**只要开着任意一条，插电期间就会自动判定，
  不用打开悬浮窗**
- 无任何联网、无广告、无第三方 SDK，依赖只有 androidx core / appcompat / material / activity

## 悬浮窗手势

| 操作 | 效果 |
| --- | --- |
| 拖动面板 | 移动悬浮窗（贴到状态栏时从面板下方的透明抓手区起手） |
| 单击面板 | 打开设置页（锁定状态同样有效） |

位置也可以用设置页里的 ▲▼◀▶ 按钮逐 5 px 微调（支持长按连发），比手拖更准。

## 主题背景

「更多 → 主题」里点「背景图/视频」会**直接打开相册**（系统图片选择器，照片和视频在一起挑），
选完当场复制一份进应用私有目录（`files/bg_image.jpg` / `files/bg_video.mp4`），
之后**在相册里删掉原图原片，背景照样在**；视频超过 60 MB 会提示换一段短的。

- 照片按 centerCrop 铺满，视频用 `TextureView` 静音循环播放（同样 centerCrop），两者共用下面两个滑块
- 背景透明度 0~100：0 = 只剩背景色，100 = 原样
- 背景模糊 0~100：Android 12 及以上走 GPU 的 `RenderEffect`，只糊背景那一层，滑块拖动时是连续的，
  文字和数字不受影响；更早的系统退回"缩小再放大"的近似做法
- 背景只作用于设置页和档案页，悬浮窗本身不跟着换；页面铺到状态栏底下，状态栏图标按背景亮度自动转白或转黑
- 视频只在页面可见时解码播放，离开页面就释放；嫌背景太花就把模糊调高、透明度调低

## 档案与提醒

**档案**：一次插电到拔电算一条记录，由充电记录服务每 5 秒采一个点，超过 500 点自动整体抽稀（间隔翻倍）。
每条记录存时长、起止电量、峰值 / 均值功率、温度峰值，以及**电流对时间积分**得到的充进容量（mAh，
比按 1% 电量倒推细）。档案页上面是选中记录的折线图（X 轴分钟，左轴功率 W、右轴电量 %），
下面是历史列表，点任意一条切换曲线。记录写在应用私有目录的 `files/charge_sessions.jsonl`，
只保留最近 60 条，卸载即清空，**全程不联网**。

记录和悬浮窗**互不依赖**：插电广播（`ACTION_POWER_CONNECTED`）会拉起一个只在充电期间存在的前台服务来记档案，
不显示悬浮窗也照记；拔线一分钟后它自己退出。代价是充电期间通知栏多一条静默通知（`充电记录` 渠道，最低优先级），
不想要就在「更多 → 高级」里关掉「充电时后台记录」。进行中的会话每 30 秒往 `charge_session_current.json` 落一次断点，
进程被杀最多丢 30 秒：下次启动还在充电就接着同一条会话记，已经拔掉就直接归档，不会留下半条记录。
另外短于 30 秒、采样点不足 3 个的插拔会直接丢弃。

同一个后台服务也负责判定四条提醒：只要开着任意一条，它就会在插电时被拉起来。
通知栏那条静默通知撤不掉 —— 实测把它 `stopForeground` 掉之后息屏一分多钟进程就被冻结、采样循环停摆，
提醒不再触发。所以记录关掉、只剩提醒时，通知文案会换成「充电提醒监控中」；要彻底不留通知，
就得把「充电时后台记录」和四条提醒全部关掉。

**提醒**（设置页「更多 → 提醒」里，全部走 `充电提醒` 这个独立通知渠道）：

| 提醒 | 触发条件 | 默认 |
| --- | --- | --- |
| 高温提醒 | 电池温度 ≥ 阈值（关闭 / 36 / 38 / 40 / 42 / 46 / 48 / 50 ℃），回落到阈值 -2 ℃ 以下才允许再次提醒 | 42 ℃ |
| 慢充提醒 | 插电满 5 分钟，近一分钟均功率 < 阈值（关闭 / 2 / 4 / 6 / 8 / 10 W）；电量 ≥80% 时不判定 | 关闭 |
| 涓流提醒 | 电量 ≥80% 且近一分钟均功率 < 阈值（关闭 / 2 / 3 / 5 W），说明快充已经结束 | 3 W |
| 充满提醒 | 框架报 `BATTERY_STATUS_FULL` 或电量 ≥100% | 开 |

四条都是**每次插电最多提醒一次**，拔掉再插重新计；判定跟着记录跑在同一个 5 秒采样循环里，
**悬浮窗开不开都会提醒**（但四条都只在插电期间判定，拔线后服务一分钟内退出）。

## 读数从哪来

第三方应用读不到真实的充电电流，本应用按可用性依次降级：

1. **FRAMEWORK** — `BatteryManager.getIntProperty(BATTERY_PROPERTY_CURRENT_NOW)`，取最近几秒的**电流幅值均值**。
   正负号不信 HAL（本机这颗天玑在 PC USB 口上是脉冲充电，瞬时电流本身就在 +0.47 A ↔ −0.47 A 之间交替），
   而是按框架报的充电状态统一盖：**插电 / 充电中显示正数，拔掉充电器后显示负数（电池在放电）**；
   插拔瞬间会清空采样窗，不会把上一个方向的读数拖过来。
   均值窗有个副作用：插上大功率充电器后硬件电流一帧就到满幅，均值却被插电前的小电流样本拖着，
   功率要爬 6 秒才追平。所以幅值一旦跳档（新样本 ≥ 均值 2 倍、向上差 ≥ 0.3 A / 向下差 ≥ 0.5 A、
   且新样本本身 ≥ 0.3 A）就判定为插拔或换充电器，窗口立即只留这一条样本，实测插上后当帧显示 7.6 W、
   拔线后 1.3 秒落回放电真值；低于 0.3 A 的样本一律不采信，避免脉冲低点让功率瞬间掉到接近 0。
2. **SYSTEM_FILE** — `/sys/class/power_supply/**/current_now`。绝大多数 ROM 已对普通应用关闭读取，
   需要在设置里手动开启，失败会自动降级。
3. **CHARGE_COUNTER** — 用库仑计 `BATTERY_PROPERTY_CHARGE_COUNTER` 差分算电流。
4. **ESTIMATED** — 用电池容量 × 电量百分比变化速率估算，只能看个趋势。

电压来自 `EXTRA_VOLTAGE`（mV），温度来自 `EXTRA_TEMPERATURE`（0.1 ℃），
标称容量通过反射 `PowerProfile.getAveragePower("battery.capacity")` 获取，失败时可手填。

已验证机型：Redmi Note 10 Pro（M2104K10AC / chopin，Android 13，HyperOS V14.0.8.0.TKPCNXM），1080×2400，440 dpi。

## 构建

环境：JDK 17+（实测 JDK 21）、Android SDK platform 34、随仓库的 Gradle Wrapper。

```sh
sh ./gradlew assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk

sh ./gradlew assembleRelease
# 产物：app/build/outputs/apk/release/app-release.apk —— R8 混淆 + 优化，约 2.0 MB
```

release 构建启用了 R8（`proguard-android-optimize.txt` + `app/proguard-rules.pro`）。
四个 manifest 组件由 AGP 自动 keep，反射只指向框架类 `PowerProfile`，因此不需要额外 keep 规则。
release 目前借用 debug 密钥签名，否则产物未签名、无法装机；换正式密钥请先建 keystore 并配 `signingConfig`。

离线环境下加 `--offline`（依赖需已在本机 Gradle 缓存中）。

## 安装与首次使用

不想自己编译的话，直接下载 Release 里的安装包（约 2.0 MB）：

- 最新版本列表：<https://github.com/xx9926/chargehud/releases/latest>
- 当前最新 v2.0 直链：<https://github.com/xx9926/chargehud/releases/download/v2.0/chargehud-v2.0.apk>
  （2,072,036 字节，MD5 `8c5278e07042248705c25c78bcfc57e3`）

安装包用 **debug keystore** 签名（个人调试签名），把 apk 传到手机上点开安装即可；
国内网络直连 GitHub 常被重置，下载时需要走代理。

用 adb 安装：

```sh
adb install -r -t chargehud-v2.0.apk
```

装好后打开「显示悬浮窗」开关即可。MIUI / HyperOS 上还需要注意三件事：

- **通知默认是关的**：应用信息 → 通知管理 → 打开「允许通知」，否则常驻通知不显示，
  通知上的「关闭悬浮窗 / 锁定」按钮也就看不到。
- **磁贴要手动添加**：下拉控制中心 → 编辑 → 在「未添加开关」里点一下「充电悬浮」即可加入。
- 放行「显示悬浮窗」和「自启动」，并把电池优化设为不限制，否则后台服务会被回收。

## 说明

本工程为独立实现，所有代码均基于 Android 公开 API 编写。
